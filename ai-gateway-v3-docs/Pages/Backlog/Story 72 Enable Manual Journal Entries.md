### **Story 7.2: Enable Manual Journal Entries**

- **As a trader,** I want to be able to add manual text and image entries to my journal,

- **so that** I can record my market observations and emotional state for later review.

- **Acceptance Criteria:**

    1. The Journal page has a feature to create a new manual entry.

    2. The user can input multi-line text to capture their thoughts.

    3. The user can optionally upload an image (e.g., a chart screenshot) with their entry.

    4. Manual entries are displayed chronologically alongside automated trade logs.
