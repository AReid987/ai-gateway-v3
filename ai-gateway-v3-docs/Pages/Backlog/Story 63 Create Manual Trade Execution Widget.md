### **Story 6.3: Create Manual Trade Execution Widget**

- **As a trader,** I want a simple interface on the dashboard to manually execute market buy/sell orders,

- **so that** I can act on my own discretion.

- **Acceptance Criteria:**

    1. The dashboard includes a "Manual Trade" widget.

    2. The widget has input fields for Symbol, Quantity, and a selector for Side (Buy/Sell).

    3. Submitting the trade requires a confirmation step.

    4. Upon confirmation, a secure request is sent to the backend to be processed by the Execution Agent.

    5. The user receives a clear notification indicating whether the order was successfully submitted or failed.
