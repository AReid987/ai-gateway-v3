## Epic 6: Interactive Trading Cockpit

**Goal:** To provide the trader with a central command center for monitoring and manual intervention.

### **Story 6.1: Display Real-Time Portfolio and Agent Status**

- **As a trader,** I want a real-time dashboard that displays my overall portfolio P&L and the status of my live agents,

- **so that** I have immediate operational awareness.

- **Acceptance Criteria:**

    1. The main "Dashboard" page displays the user's total portfolio Profit and Loss (P&L) for the current trading day.

    2. The P&L value updates in near real-time without requiring a page refresh.

    3. A dedicated "Agent Status" panel on the dashboard lists all of the user's configured agents.

    4. Each agent's status (e.g., "Active," "Idle," "Error") is clearly displayed and updates automatically.
