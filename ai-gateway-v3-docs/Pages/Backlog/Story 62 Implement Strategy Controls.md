### **Story 6.2: Implement Strategy Controls**

- **As a trader,** I want to have start/stop controls for my automated strategies on the dashboard,

- **so that** I have direct oversight.

- **Acceptance Criteria:**

    1. Next to each strategy listed in the "Agent Status" panel, there are interactive "Start" and "Stop" buttons.

    2. Clicking "Start" on an "Idle" strategy sends a command to activate it for live trading, and the UI status updates to "Active."

    3. Clicking "Stop" on an "Active" strategy sends a command to deactivate it, and the UI status updates to "Idle."

    4. The user receives a confirmation notification upon a successful action.
